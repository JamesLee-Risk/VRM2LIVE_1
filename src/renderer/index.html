VRM2LIVE

基於隱私原則，本軟體在任何介面均不顯示攝影機畫面（FR-02-20）。

語音口型

母音校準：按下按鈕後持續發出該母音約 1 秒。若模型口型與你的聲音對不上， 校準通常能顯著改善（不同人的共振峰頻率差異可達 ±15%）。

靈敏度

點擊即可開關表情，不需先建立熱鍵（FR-05-08）。

支援 .vrma（VRM Animation）與 .bvh。 把檔案放進 Animations/ 資料夾後按重新掃描。

循環待機動畫

待機動畫的優先權低於臉部追蹤，因此身體會動、頭部仍跟著你轉。

一次性動畫

「停在最後一幀」不會凍結由追蹤驅動的骨骼——那些骨骼在動畫結束後會自動交還給追蹤。

靜態姿勢

把目前的骨骼姿勢存成可開關的姿勢，供 TogglePose 熱鍵使用。

小鍵盤數字可獨立綁定（顯示為「小鍵盤1」），與主鍵盤數字列互不衝突。 可搭配最多兩個修飾鍵，例如 Ctrl + 小鍵盤1，避免打字時誤觸。

畫面按鈕

最多 8 個，顯示於舞台右側。輸出畫面中不會包含這些按鈕（FR-15-14）。

外部觸發

供 Stream Deck 等工具以 HTTP 觸發。僅綁定 127.0.0.1，且必須帶權杖。
